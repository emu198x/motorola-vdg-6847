# motorola-vdg-6847

The Motorola MC6847 video display generator.

| Crate | Registry |
|---|---|
| [`emu198x-motorola-vdg-6847`](crates/emu198x-motorola-vdg-6847) | [crates.io](https://crates.io/crates/emu198x-motorola-vdg-6847) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Acorn Atom and Dragon 32.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
